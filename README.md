# 🌐 Student Portfolio Project

## Project Title
**Student Portfolio Website**

---

## Project Description
A personal portfolio website built using **HTML, CSS, and JavaScript**.  
It showcases my academic background, certifications, internship experience, skills, and contact details in a clean, responsive, and user‑friendly design.  
The site also includes a **dark mode toggle** for better accessibility and user experience.

---

## Objectives
- To create a professional portfolio showcasing my education, skills, and achievements.  
- To practice and apply web development concepts using HTML, CSS, and JavaScript.  
- To build a responsive and interactive website that can be hosted online.  
- To provide recruiters and peers with an easy way to view my resume and contact details.  

---

## Technologies Used
- **HTML5** – Structure and content.  
- **CSS3** – Styling, layout, responsiveness, pastel theme.  
- **JavaScript** – Interactivity (dark mode toggle, smooth transitions).  

---

## Features
- **Dark Mode Toggle** – Switch between light and dark themes.  
- **Responsive Layout** – Works across desktop and mobile devices.  
- **Navigation Bar** – Smooth access to all sections.  
- **Resume** – Direct button to view my resume.  
- **Contact Section** – Includes phone, email, and GitHub profile link.  

---

## Project Structure
```text
student-portfolio/
│
├── index.html        # Main structure of the portfolio
├── style.css         # Styling and layout
├── script.js         # Dark mode toggle and interactivity
├── resume.pdf        # Resume file linked in the portfolio

```
